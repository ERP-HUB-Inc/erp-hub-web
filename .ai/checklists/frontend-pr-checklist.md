# Frontend Pull Request Checklist

Before opening PR, check:

- [ ] Code follows existing project pattern.
- [ ] TypeScript errors are fixed.
- [ ] Lint errors are fixed.
- [ ] No unrelated files changed.
- [ ] UI works on expected screen sizes.
- [ ] Loading state is handled.
- [ ] Empty state is handled where needed.
- [ ] Error state is handled.
- [ ] Form validation works.
- [ ] Permissions are respected.
- [ ] Sensitive data is not fetched or shown too early.
- [ ] API request payload is correct.
- [ ] API error response is handled.
- [ ] Snackbar/toast message is correct.
- [ ] Manual QA steps are written.
