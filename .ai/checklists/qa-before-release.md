# QA Before Release Checklist

Use this before handing work to QA.

## General

- [ ] Page loads without console errors.
- [ ] Main action works.
- [ ] Cancel/back behavior works.
- [ ] Refresh behavior is acceptable.
- [ ] Error messages are understandable.

## Forms

- [ ] Required fields validate.
- [ ] Invalid format validates.
- [ ] Past date/time is blocked where needed.
- [ ] Submit button behavior is correct.
- [ ] Draft behavior is correct if supported.

## Permissions

- [ ] User with permission can access feature.
- [ ] User without permission cannot access restricted behavior.
- [ ] Sensitive data is not visible before verification.

## UI

- [ ] Responsive layout checked.
- [ ] Long text does not break layout.
- [ ] Copy button copies correct value only.
