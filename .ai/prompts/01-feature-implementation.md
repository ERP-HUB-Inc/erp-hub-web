# Prompt: Feature Implementation

Use this when asking an AI agent to build a frontend feature.

```txt
You are working in my React / Next.js / TypeScript frontend project.

Task:
<describe the feature>

Business rule:
<describe important rules>

Expected UI behavior:
<describe what user sees and does>

API behavior:
<describe endpoint/request/response if known>

Constraints:
- Follow AGENTS.md.
- Reuse existing components and patterns.
- Do not make unrelated changes.
- Keep TypeScript safe.
- Add/update tests if the project already has tests.

After finishing, summarize:
- Files changed
- What changed
- How to test manually
```
```
