# Prompt: Bug Fix

Use this when asking an AI agent to fix a frontend bug.

```txt
Bug:
<describe the bug>

Current behavior:
<what happens now>

Expected behavior:
<what should happen>

Steps to reproduce:
1. <step>
2. <step>
3. <step>

Known files/components:
<list files if you know>

Constraints:
- Follow AGENTS.md.
- Find the root cause before editing.
- Make the smallest safe fix.
- Do not break existing behavior.
- Add/update tests if possible.

After finishing, explain:
- Root cause
- Fix
- Manual test steps
```
```
