# Prompt: Code Review

Use this when asking an AI agent to review code.

```txt
Review this frontend change like a senior React / TypeScript engineer.

Focus on:
- Correctness
- Type safety
- Form validation
- API handling
- Permission/security issues
- UI/UX consistency
- Accessibility
- Possible QA edge cases

Please return:
1. Critical issues
2. Suggestions
3. Good parts
4. Final recommendation: approve or request changes
```
```
