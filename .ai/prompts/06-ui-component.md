# Prompt: UI Component

Use this when asking an AI agent to create or modify a reusable component.

```txt
Create/update a reusable frontend component.

Component name:
<name>

Purpose:
<what it should do>

Props:
<list props>

States:
- Default
- Loading
- Error
- Disabled
- Empty if relevant

Constraints:
- Follow AGENTS.md.
- Reuse existing design system tokens/components.
- Keep it accessible.
- Keep TypeScript props clear.
- Do not add a new library unless necessary.

After finishing, provide usage example.
```
```
